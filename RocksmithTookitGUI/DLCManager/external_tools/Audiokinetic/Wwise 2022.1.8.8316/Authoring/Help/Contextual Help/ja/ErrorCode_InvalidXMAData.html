Invalid XMA data - Make sure data is allocated from APU memory and is aligned to 2K.

エラーテキストのとおり、XMAデータはすべて、2KBバウンダリにアライメントを行う必要があります。通常、Wwiseが管理するXMAメディアに対して、SoundBankやストリーミングファイルを通して行われます。ただしこの制限に、メディアを管理するゲームコードが従う必要があります。 AK::SoundEngine::LoadBank（メモリポインターバージョン）や、 AK::SoundEngine::SetMediaを使うと、このエラーが発生することがあります。

考えられる原因:

  • メモリポインタが、 AK::SoundEngine::LoadBankや、 AK::SoundEngine::SetMediaへのコールで、2,048 bytesにアライメントされていません。

推奨される解決策:

  • 関数のコール前にメモリアライメントを行います。
