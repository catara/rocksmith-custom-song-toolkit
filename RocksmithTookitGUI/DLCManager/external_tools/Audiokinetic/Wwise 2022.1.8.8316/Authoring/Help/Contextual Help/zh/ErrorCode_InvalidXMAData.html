Invalid XMA data - Make sure data is allocated from APU memory and is aligned to 2K.

“XMA 数据无效 - 确保从 APU 内存分配数据并对齐至 2K 边界点”。正如错误文本所述，所有 XMA 数据都要对齐至 2 KB 边界点。由 Wwise 通过 SoundBank（音频包）或流播放文件管理的 XMA 媒体通常都已对齐。不过，用于管理媒体的游戏代码也须遵守此约束。在使用 AK::SoundEngine::LoadBank（内存指针版本）和 AK::SoundEngine::SetMedia 时，可能会发生此错误。

可能的原因：

  • 在调用 AK::SoundEngine::LoadBank 或 AK::SoundEngine::SetMedia 时，内存指针未对齐至 2,048 字节。

推荐的解决步骤：

  • 在调用函数前对齐内存。
