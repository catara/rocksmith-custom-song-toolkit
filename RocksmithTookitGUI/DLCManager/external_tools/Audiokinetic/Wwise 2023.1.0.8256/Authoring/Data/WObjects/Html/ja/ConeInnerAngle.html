Cone inner angle

減衰が発生しないエリアを示す角度。

The Cone inner angle defines the top boundary in the Cone Preview. 数値が変わるとリアルタイムに再描写される。

内側と外側の角度の間のエリアを、トランジションエリアと呼ぶ。The volume attenuation within this area is linearly interpolated between zero attenuation and the Cone max attenuation value.

単位：°

Default value: 90
Range: 0 to 360
