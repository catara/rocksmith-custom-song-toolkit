Cone outer angle

ボリューム、ローパスフィルタ、そしてスプレッド減衰が最大レベルで維持されるエリアを示す角度。

The Cone outer angle defines the bottom boundary in the Cone Preview. 数値が変わるとリアルタイムに再描写される。

内側と外側の角度の間のエリアを、トランジションエリアと呼ぶ。The volume attenuation within this area is linearly interpolated between zero attenuation and the Cone max attenuation value.

単位：°

Default value: 245
Range: 0 to 360
