Cone inner angle

内角。该角度用于定义不发生衰减的区域。

The Cone inner angle defines the top boundary in the Cone Preview. 在修改值时实时重新绘制。

内角和外角之间的区域称为过渡区。The volume attenuation within this area is linearly interpolated between zero attenuation and the Cone max attenuation value.

单位：°

Default value: 90
Range: 0 to 360
