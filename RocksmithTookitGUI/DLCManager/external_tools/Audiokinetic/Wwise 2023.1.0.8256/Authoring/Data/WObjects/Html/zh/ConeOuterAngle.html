Cone outer angle

外角。该角用于定义音量、低通滤波器、扩散和焦点衰减保持其最大电平的区域。

The Cone outer angle defines the bottom boundary in the Cone Preview. 在修改值时实时重新绘制。

内角和外角之间的区域称为过渡区。The volume attenuation within this area is linearly interpolated between zero attenuation and the Cone max attenuation value.

单位：°

Default value: 245
Range: 0 to 360
