XMA decoding error.

The XMA hardware decoder reported a fatal error.

Probable causes:

  • Corruption of the XMA file.

  • Discrepancy between SoundBank and streamed file, when using Zero Latency. This is possible if there were a packaging or console deployment error.

Recommended resolution steps:

  • Clear the audio file cache and reconvert the XMA files.

  • Regenerate the SoundBank.

  • Redeploy the game data.
