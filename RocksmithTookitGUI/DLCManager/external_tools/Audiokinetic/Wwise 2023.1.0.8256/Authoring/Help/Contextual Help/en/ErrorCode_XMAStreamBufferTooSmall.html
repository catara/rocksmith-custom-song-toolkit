Failed seeking in XMA source: stream buffer is smaller than XMA block size.

Seeking failed for an XMA encoded streamed sound. To properly seek, a full XMA packet must be contained in a streaming block.

Recommended resolution steps:

  • Enlarge the AkDeviceSettings::uGranularity parameter.

  • Change the codec used for the failing sound. You can track the sound causing this issue by following the connected dot indicators in the Capture Log to trace back to the Event that initiated the playback.

  • Put the sound in a SoundBank instead of streaming it.
