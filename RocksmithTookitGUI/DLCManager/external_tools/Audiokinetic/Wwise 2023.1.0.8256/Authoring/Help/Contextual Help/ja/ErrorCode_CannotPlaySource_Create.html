Failed creating source.

Generic error indicating that an audio source could not be started.

考えられる原因:

  • ソースが、非登録プラグインを使っています。このエラーより先に、プラグインエラーが発生した可能性があります。

  • ソース作成のメモリが不足している（先にメモリ不足エラーが表示されているはず）

  • このソース用バスが存在しない。Init SoundBankが最新でない可能性があります。

  • 予期しないエラー。

推奨される解決策:

  • Check for out-of-memory errors in the log and resolve them by allocating more memory. See 「Memory allocation failed.」.

  • Init SoundBankが、このソースを含むSoundBankと同期しているか、確認します。SoundBanksを再生成し、再コピーします。

  • Contact Audiokinetic Support. 理想的には、問題の再現中にProfilingSession.profをキャプチャーします。(Refer to ??? for details.)
