Error while loading bank.

This error that indicates the SoundBank loading process failed while decoding the SoundBank structures. This is a last resort, catch-all error. このエラーより先のエラーを、Capture Logで確認してください。

考えられる原因:

  • ディスクに破損したSoundBankがあります。

  • 未対処のメモリ不足エラーが発生しました。バグとしてレポートする必要があります。

  • 予期しないエラー。

推奨される解決策:

  • ログにメモリー不足エラーがあれば、解消する。

  • SoundBanksを再生成し、ターゲットコンソールにリデプロイします。

  • Contact Audiokinetic Support. 理想的には、問題の再現中にProfilingSession.profをキャプチャーします。(Refer to ??? for details.)
