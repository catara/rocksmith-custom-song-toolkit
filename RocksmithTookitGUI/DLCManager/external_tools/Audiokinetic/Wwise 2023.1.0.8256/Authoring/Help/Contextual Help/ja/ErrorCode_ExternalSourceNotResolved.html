External source missing from PostEvent call.

A call to AK::SoundEngine::PostEvent was made with an Event that requires one or more External Source file replacements. APIコールに、必要なすべてのソースが含まれていませんでした。Note that it is possible to have multiple External Sources in a single Event and that all of them must be provided in code at runtime. The External Source ID must match as well.

推奨される解決策:

  • Wwiseプロジェクトで、イベントのターゲットと、そのイベントに必要なExternal Sources数を、検証します。文字列または数値の識別子を、確認します。これらのIDをPostEventに提供する必要があります。In the call to PostEvent, make sure the same number of External Sources is present in the array, and that their IDs match the ones in the Wwise project.
