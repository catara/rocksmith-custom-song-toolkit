Maximum number of hardware-accelerated voices reached. Voice will not play.

ハードウェアアクセラレーションのオーディオフォーマットを使う、同時再生中のボイスが、多すぎます。

考えられる原因:

  • あなたが使っているコンバージョン設定が、同じオーディオフォーマットをソフトウェアでデコードするほかのプラットフォームと、同じコンバージョン設定です。一部のオーディオフォーマットは、特定のプラットフォームで、自動的にハードウェアアクセラレーションを使うことがあります。

  • あなたは、マルチチャンネルのハードウェアアクセラレーションのサウンドを、大量に使っています。一部のプラットフォームではチャンネル数が上限数を切り崩していくので、例えば同時にデコードできるモノやステレオのソースの方が、5.1や7.1のソースよりも多くなります。

  • バーチャルボイスのスレッショルド設定が低すぎます。

推奨される解決策:

  • 一部のサウンドにおいて、別のコンバージョン設定を使います。Consult Audio Formats for advice on which conversion setting is best for different platforms and use cases.

  • Limit the number of concurrent sounds using a hardware-accelerated audio format.

  • ハードウェアアクセラレーションのサウンドに、モノソースやステレオソースを使います。

  • バーチャルボイスのスレッショルドを上げます。
