Invalid file header.

ストリーミングファイルのファイルヘッダが破損しているため、または対応していないファイルタイプのため、デコードできなかったことを示します。このエラーが発生したサウンドもエラーと共に報告されます。

考えられる原因:

  • ファイルの破損

  • ファイルのコンバージョンに、Wwiseの正しくないバージョンを使用した。

  • A non-WEM format file was used with AkExternalSource.

推奨される解決策:

  • ファイルをもう一度コンバージョンしてコピーする。

  • ゲームで使うサウンドエンジンに対応できるWwiseのバージョンを使う。

  • Use WEM files when using AkExternalSource.

  • 解析するために、元のファイルとコンバージョン後のファイルをAudiokineticサポートに送る。
