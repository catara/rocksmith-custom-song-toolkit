Invalid floating point value detected : non-finite(or NaN) priority.

ある音のPriorityパラメータが、無効値として検知されました。一部の音のプライオリティが、計算されません。

考えられる原因:

  • 無効なインプット値が、SoundEngine APIに送られました。Typically, this would be caused by an RTPC or a Position.

推奨される解決策:

  • Enable API Calls in the Profiler Settings and reproduce the scenario. APIコールで、無効値を示す新しいエラーを探します。

  • Contact Audiokinetic Support if the problem persists.
