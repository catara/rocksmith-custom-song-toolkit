Opus decoder failure.

Opusデコーダーが破損したストリームに遭遇したため、音をさらにデコードすることができません。音が停止します。

考えられる原因:

  • If the sound has the Zero Latency option enabled, the media portion that is in the SoundBank doesn't match the WEM file that is streamed after the Zero Latency buffering is consumed. 発生原因として、以下が考えられます:

    • An error in the packaging or deployment of the SoundBank and WEM files in the game. ファイルの1つでもコピーを失敗すると、この問題が起きます。

    • 音が2つのSoundBankで重複しているので、Zero Latencyの部分も重複しています。1つのSoundBankだけが再生成されると、この問題が起きる可能性があります。

    • ゲームに最新でないSoundBankがロードされています。

  • このストリームを読み込む際にI/Oフックで問題が発生。カスタムI/Oフックの使用に関係することが、よくあります。

  • An internal Wwise bug.

推奨される解決策:

  • あなたのSoundBanksを再生成します。

  • オーディオファイルのキャッシュをクリアにして、WEMファイルを再変換します。ファイルキャッシュをクリアにするには、Fileメニューで選択するか、.cacheフォルダの該当するWEMファイルをマニュアル操作で削除します。

  • Use a different codec in the Conversion Settings.

  • If this problem persists, contact Audiokinetic Support.
