SetMixer: Plug-in instanciation failed.

This error originates from AK::SoundEngine::SetMixer. It will happen only if there wasn't enough memory to initialize the plug-in. このエラーより先に、必ず"Insufficient Memory"エラーが表示されるはずです。

Recommended resolution step:

  • Check 「Memory allocation failed.」 for solution to the memory allocation failure.
