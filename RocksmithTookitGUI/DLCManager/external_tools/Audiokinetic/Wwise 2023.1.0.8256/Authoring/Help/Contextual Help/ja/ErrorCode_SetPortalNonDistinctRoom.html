AK::SpatialAudio::SetPortal: Portal must have a front room which is distinct from its back room.

2つの異なるRoomをPortalで接続する必要があります。 AK::SpatialAudio::SetPortal に対し、 AkPortalParams::FrontRoom や AkPortalParams::BackRoom 経由でパスされるRoom IDが、同じものです。

推奨される解決策:

  • Profile the API calls the game is making by enabling API Calls in the Profiler Settings (Alt-G). シナリオを再テストして、エラー前にこのファンクションに送られたパラメータを確認します。

  • AkPortalParams::FrontRoom や AkPortalParams::BackRoom で指定し、 AK::SpatialAudio::SetPortal にパスするRoomsは、必ず異なるRoomとします。
