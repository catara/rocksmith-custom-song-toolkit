Invalid transform in function ...

An invalid orientation has been passed to the specified function.

考えられる原因:

  • AkTransform のオリエンテーションベクトルのFrontとTopが、互いに直交しません。

  • AkTransform のオリエンテーションベクトルのFrontとTopの1つ、または両方の長さが、1に等しくありません。

推奨される解決策:

  • Profile the API calls the game is making by enabling API Calls in the Profiler Settings (Alt-G). シナリオを再テストして、エラー前にこのファンクションに送られたパラメータを確認します。
