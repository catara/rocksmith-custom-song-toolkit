AkOutputDeviceID not found as an active device in call to function ...

This error occurs when Wwise cannot find a device in use by the sound engine that matches the provided AkOutputDeviceID.

권장 해결 단계:

  • Debug 버전을 사용하여 게임에 디버거를 첨부한 채 동일한 상황을 재시도해보세요.

  • Check that the AkOutputDeviceID being provided for replacement matches the AkOutputDeviceID used during AK::SoundEngine::Init. 제공된 AkInitSettings::settingsMainOutput에서 audioDeviceShareset가 0일 경우 초기 AkOutputDeviceID는 'System'이라는 ShareSet의 ID와 제공된 AkInitSettings::settingsMainOutput의 idDevice를 합친 것으로 설정됩니다.

  • Check that the AkOutputDeviceID being provided for replacement matches an AkOutputDeviceID previously returned from AK::SoundEngine::AddOutput() or AK::SoundEngine::ReplaceOutput().

  • 문제의 AkOutputDeviceID가 포함된 AK::SoundEngine::RemoveOutput() 호출이 실행되지 않았는지 확인하세요.
