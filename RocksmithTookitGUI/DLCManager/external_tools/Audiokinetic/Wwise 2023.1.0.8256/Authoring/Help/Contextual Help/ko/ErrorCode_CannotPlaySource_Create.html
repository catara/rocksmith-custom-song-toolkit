Failed creating source.

Generic error indicating that an audio source could not be started.

유력한 원인:

  • 음원이 등록되지 않은 플러그인을 사용하고 있습니다. 이 오류는 플러그인 오류가 발생한 후 일어날 가능성이 큽니다.

  • 음원을 생성하는 데에 필요한 메모리가 충분하지 않을 때 (이 경우 out of memory 오류가 먼저 뜨게 됩니다).

  • 이 음원이 연결된 버스가 존재하지 않을 때. Init SoundBank가 최신이 아닐 수 있습니다.

  • 예상하지 못한 오류.

권장 해결 단계:

  • Check for out-of-memory errors in the log and resolve them by allocating more memory. “Memory allocation failed.”을(를) 봐주세요.

  • Init SoundBank가 이 음원을 담고 있는 SoundBank와 동기화되었는지 확인하세요. SoundBank를 재생성하고 다시 복사하세요.

  • Contact Audiokinetic Support. 문제를 재현하는 도중 ProfilingSession.prof를 캡처링하는 것이 좋습니다. (Refer to ??? for details.)
