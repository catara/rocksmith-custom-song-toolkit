Error while loading bank.

This error that indicates the SoundBank loading process failed while decoding the SoundBank structures. This is a last resort, catch-all error. Capture Log에서 이 오류 전에 일어나는 다른 오류를 확인하세요.

유력한 원인:

  • 디스크에서 SoundBank가 손상되었습니다.

  • 처리가 되지 않은 메모리 부족 오류가 발생했습니다. 이 버그는 보고되어야 합니다.

  • 예상하지 못한 오류.

권장 해결 단계:

  • 로그에 out-of-memory 오류가 있는지 확인하고 그 오류를 먼저 해결해 주세요.

  • SoundBank를 재생성하여 대상 콘솔에 재배포하세요.

  • Contact Audiokinetic Support. 문제를 재현하는 도중 ProfilingSession.prof를 캡처링하는 것이 좋습니다. (Refer to ??? for details.)
