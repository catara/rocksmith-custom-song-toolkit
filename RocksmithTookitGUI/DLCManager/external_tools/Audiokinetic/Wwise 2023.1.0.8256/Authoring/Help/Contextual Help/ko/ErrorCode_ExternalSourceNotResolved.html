External source missing from PostEvent call.

A call to AK::SoundEngine::PostEvent was made with an Event that requires one or more External Source file replacements. API 호출에 필요한 모든 음원이 제공되지 않았습니다. Note that it is possible to have multiple External Sources in a single Event and that all of them must be provided in code at runtime. The External Source ID must match as well.

권장 해결 단계:

  • Wwise 프로젝트에서 해당 Event의 대상이 External Source가 얼마나 필요한지 확인하세요. 문자열이나 식별 번호를 메모해두세요. 이 ID를 반드시 PostEvent에 제공해야 합니다. In the call to PostEvent, make sure the same number of External Sources is present in the array, and that their IDs match the ones in the Wwise project.
