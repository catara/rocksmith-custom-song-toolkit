Failed creating hardware-accelerated voice.

This error occurs when a sound using a hardware-accelerated audio format is unable to acquire the proper resources from the platform's operating system in order to start decoding. 이 사운드는 재생되지 않습니다.

유력한 원인

  • 망가진 뱅크나 미디어가 이 문제를 일으킬 수 있습니다.

  • Exceeding the number of voices or memory reserved for hardware operations.

권장 해결 단계:

  • SoundBank와 미디어를 재생성하세요. If this does not solve the issue, this may indicate either faulty hardware or a bug in the game or Wwise itself. In this case, please contact Audiokinetic Support.
