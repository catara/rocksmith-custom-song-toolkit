Maximum number of hardware-accelerated voices reached. Voice will not play.

하드웨어로 가속되는 오디오 형식을 사용하는 보이스가 동시에 너무 많이 재생됩니다.

유력한 원인

  • 동일한 오디오 형식을 소프트웨어에서 디코딩하는 다른 플랫폼과 동일한 변환 설정을 사용하고 있습니다. 일부 오디오 형식은 특정 플랫폼에서 자동으로 하드웨어 가속을 사용하도록 선택할 수 있습니다.

  • 다채널의 하드웨어로 가속되는 사운드를 너무 많이 사용하고 있습니다. 일부 플랫폼에서는 채널의 개수가 제한값에 불리하게 적용됩니다. 예를 들어 5.1이나 7.1 음원보다 모노/스테레오 음원을 동시에 더 디코딩할 수 있습니다.

  • 가상 보이스 한계점이 너무 낮게 설정되었습니다.

권장 해결 단계:

  • 일부 사운드에 다른 변환 설정을 사용하세요. Consult Audio Formats for advice on which conversion setting is best for different platforms and use cases.

  • Limit the number of concurrent sounds using a hardware-accelerated audio format.

  • 하드웨어로 가속되는 사운드에 모노나 스트레오 음원을 사용하세요.

  • 가상 보이스 한계점을 높이세요.
