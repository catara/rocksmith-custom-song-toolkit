Opus decoder failure.

Opus 디코더가 손상된 스트림을 발견하여 더 이상 디코딩할 수 없었습니다. 사운드가 중단됩니다.

유력한 원인:

  • If the sound has the Zero Latency option enabled, the media portion that is in the SoundBank doesn't match the WEM file that is streamed after the Zero Latency buffering is consumed. 이 현상은 다음과 같은 원인으로 일어날 수 있습니다.

    • An error in the packaging or deployment of the SoundBank and WEM files in the game. 파일 중 하나라도 복사되지 않으면 이 문제가 일어나게 됩니다.

    • 사운드가 두 SoundBank에 중복되어 Zero Latency의 양 또한 중복됩니다. 한 SoundBank만 재생성된 경우 이 문제가 일어날 수 있습니다.

    • 오래된 SoundBank가 게임에 로딩되었습니다.

  • 이 스트림을 읽을 때 I/O 연결에서 문제가 생겼습니다. 이 문제는 보통 맞춤화된 I/O 연결 사용과 관련됩니다.

  • An internal Wwise bug.

권장 해결 단계:

  • SoundBank를 재생성하세요.

  • 오디오 파일 캐시를 제거하고 WEM 파일을 다시 변환하세요. 캐시 파일 제거는 File 메뉴에서 실행하거나 .cache 폴더에서 특정 WEM 파일을 직접 삭제함으로써 실행할 수 있습니다.

  • Use a different codec in the Conversion Settings.

  • If this problem persists, contact Audiokinetic Support.
