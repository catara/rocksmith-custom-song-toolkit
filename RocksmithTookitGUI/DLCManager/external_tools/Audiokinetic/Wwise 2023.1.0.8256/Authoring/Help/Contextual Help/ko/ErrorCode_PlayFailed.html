Play Failed.

This is a generic error indicating that an Event could not complete. The reason for the failure usually immediately precedes the error in the Capture Log.

권장 해결 단계:

  • Capture Log에서 해당 오류의 윗줄을 확인하세요.

  • Capture Log에서 오류를 선택하고 연결된 점 표시기를 따라가서 연관된 모든 알림 메시지를 확인하세요. One of them should provide an indication of what caused the failure.
