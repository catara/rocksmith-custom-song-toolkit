AK::SpatialAudio::SetGeometry - More than two triangles are connected to the same edge.

One of the triangles provided in AK::SpatialAudio::SetGeometry is not properly constructed. API는 두 개의 삼각형만 동일한 가장자리를 공유하도록 허용합니다.

권장 해결 단계:

  • Profile the API calls the game is making by enabling API Calls in the Profiler Settings (Alt-G). 상황을 다시 시험하여 이 오류 이전에 해당 기능에 제공된 매개 변수 값을 확인하세요.

    The error string indicates the indices in the Triangles array of the three triangles that erroneously share the same edge, and the indices in the Vertices array that form said edge.
