Invalid transform in function ...

An invalid orientation has been passed to the specified function.

유력한 원인:

  • AkTransform의 방향 벡터인 Front와 Top이 서로 직교하지 않습니다.

  • AkTransform의 방향 벡터인 Front와 Top 중 하나 혹은 모두의 표준이 (길이) 1이 아닙니다.

권장 해결 단계:

  • Profile the API calls the game is making by enabling API Calls in the Profiler Settings (Alt-G). 상황을 다시 시험하여 이 오류 이전에 해당 기능에 제공된 매개 변수 값을 확인하세요.
