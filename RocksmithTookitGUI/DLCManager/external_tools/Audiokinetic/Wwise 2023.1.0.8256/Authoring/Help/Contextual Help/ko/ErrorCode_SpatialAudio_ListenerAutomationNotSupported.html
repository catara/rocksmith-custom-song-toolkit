초기 반사는 3D Position: Listener with Automation을 사용하는 사운드에서 지원되지 않습니다. 지정된 초기 반사 버스는 무시됩니다.

When using an early reflections bus, a sound's 3D Position must be set to either Emitter or Emitter with Automation. 하지만 Emitter with Automation을 사용할 경우 반사가 여전히 방사체 위치에서만 계산됩니다. 반사 음원의 경우 자동화 상쇄값이 무시됩니다. For more information about setting up early reflections on a sound, see Spatial Audio.

Recommended resolution step:

  • In the General settings tab of the sound, clear the Early Reflections Auxiliary Bus (that is,set it to None), or change the 3D Position to Emitter in the Positioning tab.
