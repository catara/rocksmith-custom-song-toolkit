Transition not sample-accurate due to incompatible audio formats.

이 오류는 각각 다른 오디오 형식을 사용하는 두 사운드가 샘플 단위 정밀 전환 효과에서 순차적으로 재생되도록 설정되었을 경우에 일어납니다. 하드웨어로 가속되는 일부 코덱은 하드웨어에 의존하여 샘플 단위 정밀 전환 효과를 실행하기 때문에 전환 효과에 사용되는 모든 사운드는 동일한 하드웨어를 사용해야 합니다. Such transitions can exist in Random/Sequence Containers, in Interactive Music, and when using the Dynamic Sequence mechanism in code.

Recommended resolution step:

  • 관련 사운드를 찾아서 동일한 오디오 형식을 가지도록 Conversion Setting을 변경하세요.
