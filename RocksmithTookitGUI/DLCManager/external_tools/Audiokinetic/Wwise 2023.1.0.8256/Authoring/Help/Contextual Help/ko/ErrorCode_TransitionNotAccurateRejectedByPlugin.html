이 오류는 동일한 오디오 형식을 사용하지만 각각 인코딩 매개 변수가 다른 두 사운드가 샘플 단위 정밀 전환 효과에서 순차적으로 재생되도록 설정되었을 경우에 일어납니다. 하드웨어로 가속되는 일부 코덱의 경우 샘플 단위 정밀 전환 효과를 실행하기 위해서 사운드가 동일한 인코딩 매개 변수를 가져야 합니다. Such transitions can exist in Random/Sequence Containers, in Interactive Music, and when using the Dynamic Sequence mechanism in code.

Recommended resolution step:

  • 관련 사운드를 찾아낸 후 동일한 인코딩 매개 변수를 가지도록 Conversion Setting을 변경하세요.
