Unknown/Dead game object ID used in <FunctionName>. Make sure the game object is registered before using it and do not use it once it was unregistered.

이 오류는 API 기능이 알 수 없는 ID를 사용하여 호출된 Game Object ID를 필요로 할 경우에 일어납니다. The name of the function is provided for reference with the game code. 해당 Game Object가 과거에 알려진 적이 있다면 'Dead Game Object'로 기록되며 'Game Object' 열에 오브젝트의 옛날 이름이 표시됩니다. The lifetime of a Game Object starts with AK::SoundEngine::RegisterGameObj and stops with AK::SoundEngine::UnregisterGameObj. 기능 호출이 이러한 호출 전후에 만들어질 경우 이 오류가 일어납니다.

다음과 같은 호출 시퀀스는 적법한 것입니다:
AK::SoundEngine::RegisterGameObj(MyGameObjID);
AK::SoundEngine::PostEvent("Play_MySound", MyGameObjID);
AK::SoundEngine::UnregisterGameObj(MyGameObjID);

Unity 사용자

Wwise Game Object의 수명은 AkGameObj 요소의 수명을 따릅니다.

유력한 원인:

  • 해당 Game Object가 기능 호출 전에 등록된 적이 없습니다.

  • 해당 Game Object가 기능 호출 전에 등록이 해제되었습니다.

  • 해당 Game Object ID가 손상되었습니다.

  • Unity 유저의 경우 'Script Execution Order'가 잘못되면 위와 같은 상황이 일어날 수 있습니다.

권장 해결 단계:

  • Enable API Calls in the Profiler Settings. 그런 다음 상황을 재구성해보세요. In the Capture Log, the faulty call with all its parameters should appear just before the error.

  • Verify the lifetime of the Game Object with the Game Object 3D Viewer.

  • 기능 호출의 순서가 연관된 RegisterGameObj와 UnregisterGameObj 사이에 있도록 변경하세요.

  • Unity 사용자의 경우 Unity에서 'Script Execution Order'를 확인하세요.
