AkOutputDeviceID not found as an active device in call to function ...

This error occurs when Wwise cannot find a device in use by the sound engine that matches the provided AkOutputDeviceID.

推荐的解决步骤：

  • 使用 Debug 版本库，将调试程序连接至游戏，然后重现相同场景。

  • Check that the AkOutputDeviceID being provided for replacement matches the AkOutputDeviceID used during AK::SoundEngine::Init. 注意，若所提供 AkInitSettings::settingsMainOutput 中的 audioDeviceShareset 为 0，则初始 AkOutputDeviceID 将是 System 共享集的 ID。该共享集使用所提供 AkInitSettings::settingsMainOutput 中的 idDevice 混音。

  • Check that the AkOutputDeviceID being provided for replacement matches an AkOutputDeviceID previously returned from AK::SoundEngine::AddOutput() or AK::SoundEngine::ReplaceOutput().

  • 检查是否使用所述 AkOutputDeviceID 调用了 AK::SoundEngine::RemoveOutput()。
