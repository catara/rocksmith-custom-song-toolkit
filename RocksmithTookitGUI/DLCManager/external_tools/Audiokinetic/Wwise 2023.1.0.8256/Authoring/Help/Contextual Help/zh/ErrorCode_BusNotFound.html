Bus not found in Init bank.

This error can occur in multiple functions called from the game. The specific function is reported. This error means this Bus ID doesn't exist at the time of the call.

可能的原因：

  • Bus ID 拼写有误。

  • 未加载 Init SoundBank（初始化音频包），或者加载时出现错误。

  • 在更改 Wwise 工程中的总线结构后，未重新生成并重新部署 Init SoundBank。

推荐的解决步骤：

  • Compare the numeric ID of the bus with those found in the Init.txt file.

  • 在游戏构建中重新生成并重新部署 Init.bnk 文件。
