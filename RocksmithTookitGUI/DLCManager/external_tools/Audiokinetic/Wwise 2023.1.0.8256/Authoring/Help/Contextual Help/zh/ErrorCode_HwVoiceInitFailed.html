Failed creating hardware-accelerated voice.

This error occurs when a sound using a hardware-accelerated audio format is unable to acquire the proper resources from the platform's operating system in order to start decoding. 这时将无法播放该声音。

可能的原因：

  • SoundBank 或媒体损坏可能会导致出现此问题。

  • Exceeding the number of voices or memory reserved for hardware operations.

推荐的解决步骤：

  • 重新生成 SoundBank 和媒体。If this does not solve the issue, this may indicate either faulty hardware or a bug in the game or Wwise itself. In this case, please contact Audiokinetic Support.
