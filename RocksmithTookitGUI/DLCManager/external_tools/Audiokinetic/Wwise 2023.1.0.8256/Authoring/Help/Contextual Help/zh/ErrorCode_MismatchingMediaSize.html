Mismatching media size error for file ... Possibly caused by mismatching sound bank or WEM resources.

This error is only triggered for sounds that use the Zero Latency option. It indicates that Wwise has detected that the WEM file isn't the same size as when the SoundBank(s) referring to it were generated. This usually points to a problem in the generation, packaging, or deployment of SoundBanks and WEM files. This process is normally handled by the game engine.

可能的原因：

  • An error in the packaging or deployment of the SoundBank and WEM files in the game. 若未能复制其中一个文件，则会导致此问题。

  • 两个 SoundBank 中的声音重复，进而导致 Zero Latency 部分重复。若仅重新生成了一个 SoundBank，则可能出现此问题。

  • A stale SoundBank is loaded in game.

  • 在读取此音频流时，I/O 挂钩出现问题。通常与自定义 I/O 挂钩的使用有关。

  • An internal bug.

推荐的解决步骤：

  • 重新生成 SoundBank。

  • 清理音频文件缓存，并重新转码 WEM 文件。您可以通过 File（文件）菜单清理文件缓存，也可手动删除 .cache 文件夹中相应的 WEM 文件。

  • Delete all .bnk and .wem files on the test console.

  • Use a different codec in the Conversion Settings.

  • If this problem persists, contact Audiokinetic Support.
