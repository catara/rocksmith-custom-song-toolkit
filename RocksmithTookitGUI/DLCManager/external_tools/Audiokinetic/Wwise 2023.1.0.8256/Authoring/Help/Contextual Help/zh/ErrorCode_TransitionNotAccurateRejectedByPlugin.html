Transition not sample-accurate due to incompatible encoding parameters.

“因不兼容编码参数导致过渡无法精确到采样点”。若两个声音采用相同的音频格式和不同的编码参数，并设为在精确到采样点的过渡中顺序播放，则将出现此错误。有些启用了硬件加速的编解码器需要声音采用完全相同的编码参数才能执行精确到采样点的过渡。Such transitions can exist in Random/Sequence Containers, in Interactive Music, and when using the Dynamic Sequence mechanism in code.

Recommended resolution step:

  • 确认所涉及的声音，并通过更改 Conversion Settings（转码设置）来使所有编码参数保持一致。
