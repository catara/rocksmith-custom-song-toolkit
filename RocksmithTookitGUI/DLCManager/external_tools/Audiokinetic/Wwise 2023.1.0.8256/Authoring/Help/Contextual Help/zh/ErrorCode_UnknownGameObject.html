Unknown/Dead game object ID used in <FunctionName>. Make sure the game object is registered before using it and do not use it once it was unregistered.

“[FunctionName] 中使用了未知/非活动游戏对象 ID”。对于需要 Game Object ID（游戏对象 ID）的 API 函数，如果使用无法识别的 ID 来调用，将出现此错误。The name of the function is provided for reference with the game code. 若某 Game Object 曾经活跃，则将其标记为 Dead Game Object（非活动游戏对象），同时在 Game Object 列中显示对象的原有名称。The lifetime of a Game Object starts with AK::SoundEngine::RegisterGameObj and stops with AK::SoundEngine::UnregisterGameObj. 若在这些调用之前或之后执行函数调用，则将发生此错误。

请注意，以下调用序列是合法的：
AK::SoundEngine::RegisterGameObj(MyGameObjID);
AK::SoundEngine::PostEvent("Play_MySound", MyGameObjID);
AK::SoundEngine::UnregisterGameObj(MyGameObjID);

Unity 用户

Wwise Game Object 的生存期与 AkGameObj 组件的生存期一致。

可能的原因：

  • 在函数调用前从未注册 Game Object。

  • 在函数调用前已注销 Game Object。

  • Game Object ID 损坏。

  • Unity 用户：Script Execution Order（脚本执行顺序）可能有误，导致出现以上情况之一。

推荐的解决步骤：

  • Enable API Calls in the Profiler Settings. 然后，重现场景。In the Capture Log, the faulty call with all its parameters should appear just before the error.

  • Verify the lifetime of the Game Object with the Game Object 3D Viewer.

  • 更改函数调用顺序，使其介于相关的 RegisterGameObj 和 UnregisterGameObj 之间。

  • Unity 用户：查看 Unity 中的 Script Execution Order（脚本执行顺序）。
