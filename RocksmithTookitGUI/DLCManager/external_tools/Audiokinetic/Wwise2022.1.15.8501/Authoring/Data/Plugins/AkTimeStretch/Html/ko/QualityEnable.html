Stretch Mode

사용할 타임 스트레치 알고리즘의 버전입니다.

다음은 사용 가능한 옵션입니다:

  • Classic: Time Stretch는 Wwise 버전 2021.1 이하의 알고리즘을 사용합니다.
  • Transient Preserving: Time Stretch는 향상된 알고리즘을 사용합니다. 이 모드를 선택하면 Quality Level 슬라이더를 사용하여 알고리즘의 성능을 미세 조정할 수 있고 Stereo Processing 컨트롤을 사용하여 복잡한 스테레오 믹스 처리를 개선할 수 있습니다.

Default value: Classic
