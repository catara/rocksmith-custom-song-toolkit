Unknown game object ID used in function ... This ID was not registered with AK::SoundEngine::RegisterGameObj before.

このエラーはGame Object IDを必要とするAPI関数が、認識できないIDでコールされた時に発生します。関数の名前がゲームコードで参照できるように提供されます。ゲームオブジェクトのライフタイムは、AK::SoundEngine::RegisterGameObjから、AK::SoundEngine::UnregisterGameObjまでです。

Unityユーザー

Wwiseゲームオブジェクトのライフタイムは AkGameObj コンポーネントのライフタイムに従います。

考えられる原因:

  • このゲームオブジェクトが、ファンクションコール前に登録されたことがありません。

  • Game Object IDが破損しています。

  • Unityユーザーへ: "Script Execution Order"が正しくないと、上記の現象が起きる可能性があります。

推奨される解決策:

  • Profiler Settings で API Calls を有効にします。次に、あなたのシナリオを再現します。Capture Logでは、問題となっているコールとすべてのパラメータがエラー直前に表示されるはずです。

  • Game Object 3D ViewerでGame Objectのライフタイムを確認します。Capture Logと比較するため、タイムスタンプをメモしておきます。

  • 関数コールの順序を関連する RegisterGameObj と UnregisterGameObj の間に入るように変更します。

  • Unityユーザーへ: Unityの"Script Execution Order"を確認してください。
