Invalid XMA data - Make sure data is allocated from APU memory and is aligned to 2K.

As the error text says, all XMA data needs to be aligned to 2 KB boundaries. This is normally done for XMA media managed by Wwise through the SoundBanks or streamed files. However, this constraint must be respected by game code that would manage media. Usage of AK::SoundEngine::LoadBank(memory pointer version) and AK::SoundEngine::SetMediacan cause this error.

Probable causes:

  • Memory pointer is not aligned to 2,048 bytes in call to AK::SoundEngine::LoadBankor AK::SoundEngine::SetMedia.

Recommended resolution steps:

  • Align the memory prior to the function call.
