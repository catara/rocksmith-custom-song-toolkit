Invalid XMA data - Make sure data is allocated from APU memory and is aligned to 2K.

오류 사항에 적혀있듯이 모든 XMA 데이터는 2KB 경계선과 정렬되어야 합니다. 이 작업은 SoundBank나 스트리밍용 파일을 통해 Wwise가 관리하는 XMA 미디어에 실행됩니다. 하지만 미디어를 관리하는 게임 코드가 이 제약 조건에 맞추어 제작되어야 합니다. AK::SoundEngine::LoadBank(메모리 포인터 버전)과 AK::SoundEngine::SetMedia를 사용할 경우 이 오류가 일어날 수 있습니다.

유력한 원인:

  • AK::SoundEngine::LoadBank이나 AK::SoundEngine::SetMedia로의 호출에서 메모리 포인터가 2,048바이트로 정렬되지 않았습니다.

권장 해결 단계:

  • 기능 호출 전에 메모리를 정렬하세요.
