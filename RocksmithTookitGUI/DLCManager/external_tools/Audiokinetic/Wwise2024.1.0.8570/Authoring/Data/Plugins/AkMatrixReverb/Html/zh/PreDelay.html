Pre-delay

预延迟。信号进入混响单元前发生的延迟。 较长的预延迟时间可用于模拟较大的空间，这样的空间需要较长时间才能听到最早的回声。 根据预延迟与为混响指定的最短延迟线之和，将定期听到第一个反射。 While pre-delay supports exclusive RTPC, it should only be used for initialization, before playback. If an RTPC is used to change pre-delay in real time during playback, the delay buffer will be continuously re-initialized, which will cause sudden silences or changes in the reverb signal.

单位：s

Default value: 0
Range: 0 to 1
