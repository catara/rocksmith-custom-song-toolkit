Pre Delay

直接音と高密度リバーブテイルの開始までの時間を決定する。While pre delay supports exclusive RTPC, it should only be used for initialization, before playback. If an RTPC is used to change pre delay in real time during playback, the delay buffer will be continuously re-initialized, which will cause sudden silences or changes in the reverb signal.

単位：ms

Default value: 25
Range: 0 to 1000
