Pre Delay

预延迟。指定直达声与密集混响尾音开头之间的时间。 While pre delay supports exclusive RTPC, it should only be used for initialization, before playback. If an RTPC is used to change pre delay in real time during playback, the delay buffer will be continuously re-initialized, which will cause sudden silences or changes in the reverb signal.

单位：ms

Default value: 25
Range: 0 to 1000
