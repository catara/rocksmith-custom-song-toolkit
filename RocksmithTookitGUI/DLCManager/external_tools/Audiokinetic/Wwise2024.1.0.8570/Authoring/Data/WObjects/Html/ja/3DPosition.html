3D Position

3Dポジショニング（減衰、スペーシャリゼーション）のためにポジショニングを計算する方法の設定。

  • Emitter: ゲームによって決まるポジショニング。
  • Emitter + Automation: エミッターのゲームオブジェクト周りで、User-Definedの自動ポジショニング。 Edited using the Automation button.

注釈:Wwise Spatial Audio features are limited for sounds that use Emitter + Automation. Diffraction and Transmission processing is disabled for sounds that use Emitter + Automation. Furthermore, the automation offset does not apply to early reflection processing. Reflections are calculated using the base Game Object position.

  • Listener + Automation: リスナーのゲームオブジェクト周りで、User-Definedの自動ポジショニング。Edited using the Automation button.

注釈:Wwise Spatial Audio features are disabled for sounds that use Listener + Automation. This includes early reflection processing, diffraction and transmission, and room sends.

Default value: Emitter
