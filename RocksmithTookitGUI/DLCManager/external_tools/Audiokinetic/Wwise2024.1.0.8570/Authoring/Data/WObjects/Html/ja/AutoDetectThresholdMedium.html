Auto Detect Threshold Medium

あるメディアファイルの最適なサンプルレートを判断するために使用する周波数を決める、カットオフボリュームの閾値を設定する。閾値レベルが高いほど、コンバージョン処理に使うサンプルレートの品質が低くなる。

中品質のボリューム閾値とは、ノーマライズしたスペクトルの観点で使われる。

The medium quality volume threshold is used when you select the Auto Medium option from the Sample Rate list in the Conversion Settings dialog.

Default value: -40
Range: -96.3 to 0
